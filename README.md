# ✨ App de Moda Feminina ✨

> Aplicativo mobile desenvolvido para a Atividade Individual 04.

---

## Sobre o projeto

O **App de Moda Feminina** é um aplicativo desenvolvido com *React Native* e *Expo*, com o objetivo de consumir dados de uma API e exibi-los na tela.

- *Consumo de API:* busca uma lista de roupas femininas na internet.
- *Lista dinâmica:* mostra a foto, o nome e o preço de cada peça.

## Como funciona

- `useState`: guarda a lista de produtos.
- `useEffect`: busca os dados quando o app abre.
- `fetch`: faz a chamada à API.
- `FlatList`: exibe os produtos na tela.

---

## Como rodar o projeto

1. Abra a pasta do projeto no terminal.
2. Instale as dependências:

```
npm install
```

3. Inicie o app:

```
npx expo start
```

4. Leia o QR code com o aplicativo **Expo Go** no celular.

Se o QR code não conectar, use:

```
npx expo start --tunnel
```
