App de Moda Feminina

Atividade Individual 04 - React Native + Expo

Aluna: Mayara Marina

Sobre o projeto

Aplicativo feito com React Native e Expo que busca dados de uma API e mostra na tela uma lista de roupas femininas, com foto, nome e preço.

API utilizada

Fake Store API, categoria de roupas femininas:

https://fakestoreapi.com/products/category/women's%20clothing

O que eu usei
useState para guardar a lista de produtos
useEffect para buscar os dados quando o app abre
fetch para chamar a API
FlatList para mostrar a lista na tela
Como rodar
Abra a pasta do projeto no terminal
Instale as dependências:
npm install
Inicie o projeto:
npx expo start
Leia o QR code com o app Expo Go no celular

Se o QR code não conectar, tente:

npx expo start --tunnel
